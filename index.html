01 / PROPUESTA

Una experiencia digital
pensada para Beltrán.

La propuesta combina un catálogo online autogestionable con un sistema visual para Instagram. La intención es que Beltrán pueda mostrar su stock de manera clara, ordenada y profesional, mientras mantiene una identidad reconocible en sus redes.

01

CATÁLOGO

Productos organizados por categorías, con buscador, filtros, fichas individuales y consulta directa por WhatsApp.

02

AUTOGESTIÓN

El equipo podrá administrar productos, precios, categorías y disponibilidad desde WordPress + WooCommerce.

03

IDENTIDAD

10 plantillas editables + sistema de iconos para historias + guía escrita de uso visual.

PUNTO DE PARTIDA

Ordenar lo que ya funciona.

  • La comunicación actual se apoya en Trading Cards, comunidad y pasión.
  • Pokémon, Magic, One Piece y Singles aparecen como ejes claros del catálogo.
  • La estética utiliza crema, negro y bordó, con titulares fuertes y recursos editoriales.
  • El contenido no se limita a vender: también informa, explica y genera conversación.

La web y el sistema de contenido propuestos toman esos códigos como base y los ordenan en una experiencia digital más consistente.

Catálogo personalizado
y autogestionable.

Desarrollo de una experiencia de catálogo diseñada específicamente para Beltrán TCG, con frontend personalizado y una administración de productos basada en WordPress + WooCommerce.

  • Diseño responsive

  • Configuración y publicación inicial
CSV
CARGA INICIAL DE PRODUCTOS

Beltrán podrá entregar una planilla con nombre, descripción, precio y datos del producto. Levitar realizará la preparación e importación masiva de esa información. Las imágenes de cada producto serán cargadas por el equipo de Beltrán.

El sistema queda preparado para que, una vez publicado, el cliente pueda seguir agregando y actualizando productos por su cuenta.

Base técnica

WordPress + WooCommerce, con frontend personalizado. WooCommerce permite importar productos mediante CSV y dispone de filtros de catálogo por categoría, atributos, disponibilidad y otros criterios. Esto permite mantener la experiencia visual a medida sin perder una administración sencilla.

Referencia visual conceptual del catálogo. El diseño final se desarrolla a medida para Beltrán.
